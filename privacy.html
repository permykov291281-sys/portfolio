Privacy Policy — Channel Uploader

Last updated: November 10, 2026

Channel Uploader is a private tool operated by Sergey Permyakov (portfolio). It is used only to upload and manage videos on YouTube channels owned by its operator (for example, the YRSA music channel). It is not offered to the public.

What data the app accesses

When the channel owner signs in with Google, the app receives an OAuth access token with the YouTube scopes youtube and youtube.upload. With this token it can:

  • upload videos to the owner's channel;
  • edit titles, descriptions, tags, thumbnails and channel settings of the owner's channel;
  • read public statistics of the owner's channel and videos (views, likes, subscribers).

The app does not access Gmail, Google Drive, contacts or any other Google data, and it does not access other people's channels.

How the data is stored

OAuth tokens are stored in a file on a private server, readable only by the operator's user account. No data is stored in any public place, sold, or shared with third parties. Video files and texts are prepared by the operator and stay on the same private server.

Google API Services User Data Policy

Channel Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

How to revoke access

Access can be revoked at any time at myaccount.google.com/permissions (select “Channel Uploader” → “Remove access”). After that the stored token stops working and is deleted.

Политика конфиденциальности — Channel Uploader

Обновлено: 10 ноября 2026 г.

Channel Uploader — личный инструмент Сергея Пермякова. Он нужен только для загрузки роликов и управления YouTube-каналами, которые принадлежат владельцу (например, музыкальный канал YRSA). Другим людям приложение не предлагается.

К каким данным есть доступ

После входа владельца канала через Google приложение получает токен OAuth с правами YouTube (youtube, youtube.upload). С ним можно загружать ролики, менять названия, описания, теги, обложки и настройки своего канала, смотреть статистику своего канала. Доступа к почте, Google Диску, контактам и чужим каналам нет.

Где хранятся данные

Токены хранятся в файле на закрытом сервере, прочитать его может только учётная запись владельца. Данные никому не передаются и не продаются.

Как отозвать доступ

В любой момент: myaccount.google.com/permissions → «Channel Uploader» → «Удалить доступ».
